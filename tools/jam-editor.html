🎪 Jam History Editor

Add, edit, and reorder past jams here, then download the file and send it to whoever uploads site files.

Steps:
  1. Click Load existing file and pick the current jams.json if you have it, so you're editing what's already there instead of starting over.
  2. Click + Add a jam for each past jam. Fill in the name, an image URL, and a link to the jam page.
  3. Use the ↑ / ↓ arrows to set the order they'll appear on the site.
  4. Click Download jams.json, then send that file to whoever uploads site files.
